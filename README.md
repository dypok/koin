# Koin - Fast Multi-Profile Personal Finance App

Koin es una aplicación de finanzas personales ultrarrápida, offline-first, diseñada con soporte nativo para múltiples perfiles independientes (ideal para parejas, familias, compañeros de piso o separación de gastos personales/freelance) y personalización visual profunda (temas y colores configurables por perfil).
